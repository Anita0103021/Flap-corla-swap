参与钱包

按剩余 Mint 批数和 Gas 上限筛选；仅领币需有未领取份额。可手动勾选，保存时固定名单。

添加狙击目标

只加入狙击名单，不改变 Mint 工作区。

移除项目

项目将从监控列表移除，不会撤销已经发送的交易。

导入钱包私钥

每行一个 64 位十六进制私钥（可带 0x）。只接受私钥，不接受助记词。

删除本地钱包

删除后此工具无法再使用该钱包。请先确认你有私钥备份。

开启本机免密码

输入一次原钱包库密码。以后由当前 Windows 账号解锁，私钥仍加密保存。
